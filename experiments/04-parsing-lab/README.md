# Лаборатория парсинга из исследования 04

- `make_fixtures.py`: генерирует ~39 битых и пограничных входов (пустые, скан без текста, зашифрованные, обрезанные, неверное расширение, битый zip, zip-бомба, другие кодировки). Вход: папка с `req.md`, `req.docx`, `req.pdf` (их можно скопировать из `data/input/`, переименовав). Нужны `pymupdf`, `pikepdf` (`uv run --with pikepdf python ...`).
- `guard.py`: прототип проверки входа до парсинга (сигнатура, размер, шифрование, текстовый слой, доля букв) и кодов возврата.
- `salvage.py`: восстановление обрезанного PDF дописыванием trailer.
- `bomb.py`: генератор zip-бомбы в DOCX для теста защиты. Не открывай результат обычными программами.
- `probe*.py`: сравнение парсеров на наших файлах (часть сценариев зовёт `pandoc` через subprocess).

Выводы: `docs/research/04-parsing-and-broken-files.md`. Фикстуры в репозиторий не коммитим (большие), генерируем скриптом.
