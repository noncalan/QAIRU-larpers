# 41. Критик-самоответ вопросов автору: два прогона, метрики до и после

Issue #41, 26.11.2026 (ночь, Астана). Живых вызовов: 3 (бюджет задачи 3), все через `claude -p`, Opus 5.5 `high` (D-010).

| Вызов | Что | Цена по тарифу API | Время |
|---|---|---|---|
| 1 | Критик на вопросах фейкового конвейера (редактор из фикстуры #20) → `tests/fixtures/llm/questions_critic/1.json` | $0,144 | 19 с |
| 2 | Редактор заново на тех же 6 кандидатах → `run-2/llm/questions/1.json` | $0,248 | 75 с |
| 3 | Критик на вопросах второго прогона → `run-2/llm/questions_critic/1.json` | $0,126 | 20 с |

Вход обоих прогонов одинаковый: `data/input/requirements.md`, фикстуры нарезки и поиска из `tests/fixtures/llm/` (находки придуманы для тестов #15, а не настоящий проход поиска). Значит, это два прогона **шага вопросов**, а не всего агента: редактор в прогоне 1 из фикстуры #20 (записан до линтера #76, поэтому один кандидат он «пропустил», и код собрал по нему шаблонную карточку P0), в прогоне 2 свежий.

## Как повторить

```bash
uv run python experiments/41-questions-critic/record.py reports      # без вызовов: out/run-1, out/run-2
uv run python -m evals.questions experiments/41-questions-critic/out/run-1 experiments/41-questions-critic/out/run-2 --name critic
```

`record.py critic-1` и `record.py run-2` делают живые вызовы заново (1 и 2 вызова), `--dry-run` только печатает промпт.

Жаккар мест документа, о которых вопросы, между прогонами: 0,556 (прогон 1 спрашивает ещё о перечне статусов, прогон 2 нет).

**Что это значит.**

- На этом документе критик не снял ни одного вопроса: оба раза он искал ответ по всему документу и не нашёл. Отвечаемые кандидаты отсёк ещё редактор: в прогоне 2 он отклонил 2 из 6 с причиной и цитатой («заполняются тестировщиками», раздел статусов). Критик здесь страховка: снять вопрос может только сверенная цитата-ответ, а живой ответ критика показал, что противоречие он ответом не считает (Q-01 о границе месяца: «два места документа отвечают по-разному, ответа нет»).
- Главная польза на этом документе в метриках: критик пометил шаблонную карточку прогона 1 (запасной путь кода по пропущенному кандидату): без сценария, ошибки 1 и 7, «здравый смысл» и «правка однозначна». Это та же карточка, которую редактор в прогоне 2 отклонил сам. В прогоне 2 одна ошибка: вопрос о сроке push просит два решения (доля событий и нагрузка).
- Метрики «со сценарием» и «без ошибок» отмечает та же модель, что писала вопросы (Opus 5.5). Исследование 17 (п. 4.3) советует для неочевидности отдельный вызов с другим промптом: это следующий шаг, если понадобится цифра для жюри без «модель оценила сама себя».

## Не проверено

- Снятие вопроса на живом ответе: оба прогона дали 0 снятий, поэтому путь «критик нашёл ответ → код сверил цитату → вопрос снят» проверен только тестами на записанных вручную ответах (`tests/test_questions_critic.py`).
- Чужие документы (холдаут) не гоняли: бюджет задачи 3 вызова.
