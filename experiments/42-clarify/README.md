## Как повторить без модели

```bash
uv run validator data/input/requirements.md out/report.md --backend replay --replay tests/fixtures/e2e/md/run
uv run validator data/input/requirements.md out2/report.md --backend replay --replay tests/fixtures/e2e/md/run --answers examples/answers.yaml
```

Первая команда даёт прогон 1 и `out/questions.yaml`; `examples/answers.yaml` это тот же файл с ответами (10 ответов на 14 вопросов, Q-10 отложен, Q-06, Q-12 и Q-14 без ответа). Ответы правдоподобные и придуманы для демо, эталон `docs/gold/` не открывался.

Вживую прогон 2 стоит один вызов: нарезка, три прохода поиска, вопросы и критик вопросов берутся из кеша прогона 1 (для записи кеш заполнен ответами `tests/fixtures/e2e/md/run/responses/`).
