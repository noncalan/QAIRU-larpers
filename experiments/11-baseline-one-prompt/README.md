# Эксперимент 11. Проверка требований одним промптом

`cli.py` запускает Claude Code через подписку из пустого временного каталога, передаёт запрос через stdin и собирает метрики. Для запуска нужен доступный в PATH `claude` с действующим входом в аккаунт. Результаты сохраняются по имени вызова в `experiments/out/11/`. Git игнорирует этот каталог. Повторный запуск использует сохранённый JSON, в том числе при ошибке CLI. Если процесс прервался до записи результата, файл `.pending` блокирует повторную отправку под тем же именем.

Команды для PowerShell из корня репозитория, Python 3.12:

```powershell
uv run --group experiments --with pydantic python experiments/11-baseline-one-prompt/run_baseline.py
uv run --group experiments --with pydantic python experiments/11-baseline-one-prompt/cli_backend_check.py
```

`run_baseline.py` последовательно отправляет полный документ три раза. Ответы для ручной проверки лежат в `baseline_run1.md` … `baseline_run3.md`, метрики и средние значения — в `baseline_summary.json`. Каждая строка терминала содержит код возврата, время в секундах, входные и выходные токены, стоимость в USD, модель, длину ответа в символах и признак чтения из кеша.

`cli_backend_check.py` проверяет JSON-схему, сохранность кириллицы в Python и Windows PowerShell, параллельные вызовы, запуск с пустым профилем и видимый контекст с флагом `--safe-mode` и без него. В отчёте `backend_check.json` также указаны поддерживаемые флаги и время обработки полного документа, если уже есть сводка первого скрипта. Бюджет — семь обычных запросов и одна попытка без входа.

**Слепая проверка.** До окончания ручной оценки открывайте тексты дефектов только в рамках самой оценки. Терминал выводит метрики и статусы. Из текстов ответов в нём видны только первые 300 символов двух проверок контекста.
