# Доменные чек-листы

Общие чек-листы предметных областей (`*.yaml`) с триггерами: пункт включается, только если в документе есть его сущность. Делает задача «Доменные чек-листы с триггерами без подгонки» (#35).

Только универсальные знания (финтех, REST, мобильные приложения), без слов проверяемого документа. `tests/test_prompt_leak.py` проверяет эту папку.
