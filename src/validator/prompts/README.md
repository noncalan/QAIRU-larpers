# Промпты агента

Тексты промптов шагов с моделью: один файл `*.md` на системный или пользовательский промпт шага (`search_system.md`, `segment_system.md` и т. п.). Хеш этой папки идёт в паспорт отчёта, поэтому любая правка промпта видна в отчёте.

Правила (CLAUDE.md, правила 2, 3 и 5):

- никаких кусков проверяемого документа, эталонных дефектов и слов предметной области документа: примеры только из другого домена;
- текст документа подаётся в промпт как данные внутри тегов, а не как инструкции;
- правка промпта идёт с живым вызовом или цифрой eval в описании PR.

Промпты сейчас:

| Файлы | Шаг | Модель | Ответ |
|---|---|---|---|
| `search_system.md`, `search_user.md` | 4, проход поиска (#14) | Opus 5.5 | свободный текст в строгом формате, его разбирает код (`search_parse.py`) |
| `search_transfer_system.md`, `search_transfer_user.md` | 4б, перенос в JSON (#18) | Haiku 5.5 | JSON по `TRANSFER_SCHEMA` (`search_transfer.py`); вызывается, только если код не разобрал находки |

Слоты в пользовательских промптах (`{document}`, `{findings}`) подставляет `prompting.fill` за один проход, поэтому фигурные скобки в тексте документа не ломают шаблон.

`tests/test_prompt_leak.py` проверяет эту папку, `checklists/` и `lint/`.
