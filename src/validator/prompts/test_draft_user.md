Для каждой находки ниже сделай попытку тест-кейса по системным инструкциям. Значение результата берётся из документа с дословной цитатой или заменяется пропуском `[?N]` с объяснением, чего не хватает.

Как читать разметку документа. Каждый блок начинается с ID в квадратных скобках: [B012] — заголовок, абзац, пункт списка, строка таблицы или фрагмент кода; [B012.3] — третье предложение блока. Строка после ID со знаком «§» служебная: путь разделов, вид блока, номер строки в исходном файле, метка требования. В строках таблиц перед значением ячейки стоит название колонки, ячейки разделены точкой с запятой. У находок указаны места документа, о которых они, и что проверяющие считают недостающим для теста.

<документ>
{document}
</документ>

<находки>
{findings}
</находки>
