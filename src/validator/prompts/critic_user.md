Перепроверь находки ниже по системным инструкциям: по каждой реши, оставить её, понизить важность или снять, и дай дословную цитату-основание из документа.

Как читать разметку документа. Каждый блок начинается с ID в квадратных скобках: [B012] — заголовок, абзац, пункт списка, строка таблицы или фрагмент кода; [B012.3] — третье предложение блока. Строка после ID со знаком «§» служебная: путь разделов, вид блока, номер строки в исходном файле, метка требования. В строках таблиц перед значением ячейки стоит название колонки, ячейки разделены точкой с запятой. У находок указаны тип дефекта, суть, объяснение рецензента, важность по правилам кода, итог примера-свидетеля, если его строили, и цитаты, которые код уже сверил с документом.
