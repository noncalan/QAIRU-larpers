Сверь находки ревью документа требований с ответами автора по системным инструкциям: какие находки ответы закрывают, какие уточняют и какие новые дефекты из-за ответов появились.

Как читать разметку документа. Каждый блок начинается с ID в квадратных скобках: [B012] — заголовок, абзац, пункт списка, строка таблицы или фрагмент кода; [B012.3] — третье предложение блока. Строка после ID со знаком «§» служебная: путь разделов, вид блока, номер строки в исходном файле, метка требования. В строках таблиц перед значением ячейки стоит название колонки, ячейки разделены точкой с запятой. У находок указаны важность, вердикт, тип дефекта, свойство стандарта и цитаты с ID блоков. У ответов — вопрос, места документа, о которых он, выбранный вариант или свой ответ автора и находки, о которых был вопрос (номера из прошлого прогона могут не совпадать с текущими).
