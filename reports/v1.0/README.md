# v1.0: отчёт агента на сдачу по `requirements.pdf`

Это отчёт о проверке выданного документа, который команда сдаёт. Его собрал агент версии `v1.0`: тег `v1.0` стоит на коммите `644366a`, в паспорте отчёта так и написано: «Версия агента: v1.0, коммит 644366a». Файлы ниже записал агент, руками их не правили.

**Итог:** 🔴 начинать разработку и тестирование нельзя. Требований 58, нарушений 46 и ещё 2 «неясно» (не хватает сведений, чтобы решить), критичных 6, вопросов автору 14, из них 6 блокируют разработку. Цитаты всех находок (67 из 67) код сверил с документом.

## Что здесь

| Файл | Что это |
|---|---|
| [`report.pdf`](report.pdf), [`report.md`](report.md) | Отчёт по PDF-версии документа (ТЗ, п. 3: PDF обязателен). Первая страница отвечает, можно ли начинать разработку и тестирование |
| [`report.json`](report.json) | Тот же отчёт для машин: находки, цитаты, паспорт, метрики |
| [`questions.yaml`](questions.yaml) | Вопросы автору ТЗ; ответы вписываются сюда же и передаются агенту флагом `--answers` |
| [`run/`](run/) | Запись живого прогона, из которой собран отчёт: каждый вызов модели (`calls.jsonl`) и ответ модели целиком (`responses/`) |

## Как получен

**Модель работала вживую.** Ответы модели записаны живым прогоном 26.11.2026 с 22:16 до 22:29 по Астане (17:16–17:29 UTC) через подписку Claude (команда `claude -p`), профиль по умолчанию `standard`. Вызовов 8, все без ошибок, модель работала 752 с (12,5 минуты), по тарифу API это стоило бы $2,75. Это та же запись, из которой собран кандидат RC2 ([`reports/v0.9-rc2/`](../v0.9-rc2/README.md)); в `run/` её копия.

**Код после модели это v1.0.** Отчёт собран на коммите `644366a` командой replay: агент прошёл весь конвейер заново, а ответы модели взял из записи. Каждый ответ найден по ключу запроса, значит промпты, документ и модели в точности те, что при записи (иначе агент остановился бы с `LLM-015`). Паспорт отчёта говорит об этом прямо: «записанные ответы (replay): из записи 8 из 8 ответов, модель не вызывалась», время записи и 752 с работы модели.

**Почему не новый живой прогон.** Два живых прогона одного документа дают немного разные находки (разброс модели меряли отдельно, [`evals/results/summary.md`](../../evals/results/summary.md)). На этой записи построены цифры README, слайдов и расчёта ценности, поэтому на сдачу идёт она: одна база цифр. Код агента при этом финальный.

**Живой прогон на том же коде тоже есть.** 27.11 агент прогнан вживую через ключ API Anthropic на коммите `90c6ce8`, код агента в нём тот же, что в `v1.0` (`git diff 90c6ce8 644366a -- src` пустой): код 0, 9 вызовов, 745 с, $2,40, светофор тот же, все 6 критичных этого отчёта нашлись снова. Отчёт и сравнение: [`reports/api-live-2026-11-27/`](../api-live-2026-11-27/README.md).

## Что изменилось против RC2

Находки, нарезка, вопросы, итог, матрица покрытия и самопроверка совпадают с RC2 до строки (сравнение `report.json` по разделам). Код между RC2 (`f69ee0f`) и `v1.0` менял только то, как отчёт это показывает:

- паспорт при replay называет время записи и сколько работала модель, числа записаны по-русски ($2,75; 205 814 байт), технические детали вынесены в отдельную таблицу;
- в PDF знак «%» не отрывается от числа при переносе строки;
- ответы автора «не знаю», «?», «TBD» не закрывают вопрос, мелочи из ревью кода, линтер без ложных срабатываний на чужих ТЗ: на этом документе находки от этого не меняются.

## Как пересобрать

Из `main` (код агента в `src/` тот же, что на теге `v1.0`), за секунды и без сети:

```bash
uv run validator data/input/requirements.pdf out/report.pdf --backend replay --replay reports/v1.0/run
```

Выйдет тот же итог и те же находки. В паспорте будет другая дата и версия вида `v1.0-N-g<коммит>`, если запускать не с самого тега. Отчёт на сдачу собран на чистом дереве с тегом `v1.0` на `644366a`, поэтому в его паспорте версия без `-dirty`. Тег `v1.0` в GitHub ставит владелец репозитория: из облачной сессии теги не пушатся.

Отчёты RC2 по Markdown и DOCX и согласие трёх форматов лежат в [`reports/v0.9-rc2/`](../v0.9-rc2/README.md): код после модели с тех пор показ поменял, а находки нет. Витрина битых файлов: [`reports/robustness/`](../robustness/README.md).
