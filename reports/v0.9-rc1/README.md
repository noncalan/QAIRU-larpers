# Кандидат v0.9-rc1: отчёт агента по `requirements.pdf`

Отчёт о проверке выданного документа, который сделал агент на теге `v0.9-rc1` (коммит `a3e57a1`). Это страховка к сдаче: если релиз v1.0 (#56) не успеет, сдаём этот отчёт. Отчёт не правили руками: файлы ниже записал агент, и он же пересобирает их из записи вызовов модели.

## Что здесь

| Файл | Что это |
|---|---|
| [`report.pdf`](report.pdf), [`report.md`](report.md) | Отчёт по PDF-версии документа (ТЗ, п. 3: PDF обязателен). 44 страницы, первая страница отвечает, можно ли начинать разработку и тестирование |
| [`report.json`](report.json) | Тот же отчёт для машин: находки, цитаты, паспорт, метрики |
| [`questions.yaml`](questions.yaml) | Вопросы автору ТЗ; ответы вписываются сюда же и передаются агенту флагом `--answers` |
| [`run/`](run/) | Запись прогона: каждый вызов модели (`calls.jsonl`) и ответ целиком (`responses/`) |
| [`formats.md`](formats.md) | Согласие форматов: тот же документ в MD, PDF и DOCX, что агент нашёл в каждом и почему находки расходятся |
| [`formats/md/`](formats/md/), [`formats/docx/`](formats/docx/) | Прогоны по `requirements.md` и `requirements.docx` для таблицы согласия |

## Как получен

Три живых прогона 26.11.2026 с 14:25 до 14:40 по Астане, параллельно, через подписку Claude (`claude -p`), из чистого дерева на теге (в паспорте версия `v0.9-rc1` без `-dirty`):

```bash
uv run validator data/input/requirements.pdf report.pdf --profile standard --max-budget-usd 5 --backend cli
```

Профиль `standard`: 1 проход поиска Opus 5.5 `medium`, а не `submit` (`xhigh`), по решению [D-012](../../docs/decisions.md): `xhigh` на замере полноты не добавил, а проход стоит в 1,6 раза дороже.

| Формат | Код | Требований | Нарушений | Неясно | Критичных | Вопросов | Вызовов | Время, с | Цена по тарифу API, $ |
|---|---|---|---|---|---|---|---|---|---|
| **PDF (сдаём)** | 0 | 58 | 51 | 2 | 8 | 15 | 8 | 797 | 2,90 |
| MD | 0 | 58 | 52 | 4 | 9 | 14 | 9 | 852 | 3,03 |
| DOCX | 0 | 58 | 48 | 4 | 9 | 13 | 9 | 818 | 3,04 |

Цитаты всех находок сверены кодом с документом (100 % во всех трёх прогонах, `formats.md`). Деньги не списывались: прогон шёл по подписке, цена посчитана по тарифу API для сравнения.

Отчёты на 20 битых файлах, сбоях модели и неудобных документах пересобраны на том же теге: [`reports/robustness/`](../robustness/README.md) (`uv run python scripts/robustness.py`, без модели, все 20 случаев с ожидаемым кодом и диагностикой).

## Пересобрать без модели

```bash
uv run validator data/input/requirements.pdf out/report.pdf --backend replay --replay reports/v0.9-rc1/run
```

Секунды и без сети. Находки, нарезка, вопросы и итог совпадают с этим отчётом; отличаются только время, способ вызова в паспорте и строка диагностики `LLM-005` «ответы взяты из записи» (проверено 26.11).
