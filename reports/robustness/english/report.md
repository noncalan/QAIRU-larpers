### Q-01 · P0 · бизнес · срок действия кода
**Вопрос.** Посылку заложили в понедельник в 10:00; клиент вводит код в среду в 12:00 — ячейка откроется?

**Где в документе.**
- «The customer shall open the compartment with a one-time code valid for 48 hours.» (раздел «Parcel Locker Service: Software Requirements › 2. Functional requirements», таблица 1, строка 3, ячейка 2, колонка «Requirement»)
- «A one-time code shall remain valid for 72 hours after the parcel is placed.» (раздел «Parcel Locker Service: Software Requirements › 3. Non-functional requirements», строка 24)

**Почему важно.** FR-03 и NFR-02 задают разные сроки действия кода. От срока зависят открытие ячейки, момент освобождения по FR-04 и граничные тесты.
