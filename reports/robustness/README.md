# Устойчивость агента: отчёты на сбоях

Каждая строка это один прогон агента той же командой, что и обычная проверка, и отчёт, который он записал. Ни один случай не кончается трассировкой: агент пишет отчёт с причиной и подсказкой, а код возврата говорит, что случилось: 0 проверка выполнена, 3 вход прочитан частично, 4 вход не обработать, 5 сбой модели. Как это устроено: раздел «Устойчивость» в [README](../../README.md).

Версия агента: `d4f8728`. Собрано 26.11.2026 02:28 UTC командой `uv run python scripts/robustness.py`.
