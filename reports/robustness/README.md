# Устойчивость агента: отчёты на сбоях

Каждая строка это один прогон агента той же командой, что и обычная проверка, и отчёт, который он записал. Ни один случай не кончается трассировкой: агент пишет отчёт с причиной и подсказкой, а код возврата говорит, что случилось: 0 проверка выполнена, 3 вход прочитан с оговорками (частично, без текста на части страниц, пустой шаблон или не похож на требования), 4 вход не обработать, 5 сбой модели. Как это устроено: раздел «Устойчивость» в [README](../../README.md).

Версия агента: `924506e`. Собрано 26.11.2026 13:08 UTC командой `uv run python scripts/robustness.py`.

Прогоны идут без распознавания сканов (`ocr=False`), чтобы отчёты не зависели от машины: с Tesseract и русским языком агент распознаёт `scan.pdf` сам и проверяет его с кодом 3 (#38).
