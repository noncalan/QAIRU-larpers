# Архитектурные решения (ADR)

Короткие записи о ключевых решениях архитектуры агента: контекст, что решили, какие были альтернативы, что из этого следует. Формат Майкла Найгарда. ADR не повторяют журнал решений: подробности и цифры лежат в [`docs/decisions.md`](../decisions.md) и в файлах, на которые ADR ссылаются. Общая картина: [`docs/architecture.md`](../architecture.md).

Все шесть записей сделаны задним числом 26.11.2026 по решениям 25–26.11 и сверены с кодом `main` на коммите `6fe67af`.

| ADR | Решение | Статус | Журнал | Дата решения |
|---|---|---|---|---|
| [0001](0001-free-text-search-parsed-by-code.md) | Поиск пишет свободный текст, разбирает код, Haiku только запасной путь | принято | D-010 | 25.11.2026 |
| [0002](0002-code-verifies-quotes.md) | Цитаты, важность и счётчики проверяет код, а не модель | принято | D-009 | 25.11.2026 |
| [0003](0003-n-passes-merge-d011.md) | N проходов со слиянием, по умолчанию один (правило D-011) | принято, ждёт подтверждения Нурдаулета | D-009, D-011 | 26.11.2026 |
| [0004](0004-one-llm-interface-subscription-api-replay.md) | Один интерфейс модели: подписка, SDK, replay | принято | D-006, D-008, D-009 | 25.11.2026 |
