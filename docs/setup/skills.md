# Скиллы и агенты Claude Code в этом репозитории

Всё из `.claude/` подхватывается автоматически, когда ты запускаешь `claude` в папке репозитория. Ставить ничего не нужно. Скилл можно вызвать вручную командой `/имя-скилла` или просто описать задачу словами: Claude сам выберет подходящий.

## Почему не весь пакет ECC

Полный плагин ECC содержит 328 скиллов. Их описания занимают контекст, и Claude хуже выбирает нужный. Поэтому мы взяли 10 скиллов, которые нужны именно для этого кейса, и положили копии в репозиторий (источник и лицензия в `.claude/skills/THIRD_PARTY_NOTICES.md`). Автор ECC предупреждает о заражённых зеркалах: брать только из официального репозитория `affaan-m/ECC`.

## Скиллы

| Скилл | Когда использовать | Этап |
|---|---|---|
| `research-sprint` (наш) | Исследование параллельными субагентами с записью в `docs/research/` | Сейчас |
| `council` | Выбор между вариантами идеи или архитектуры: четыре голоса спорят до решения | Идея |
| `blueprint` | Разбить общий план на задачи размером с PR для нескольких людей | План |
| `architecture-decision-records` | Записать принятое решение с альтернативами | Идея и дальше |
| `eval-harness` | Eval-driven development: эталон → грейдер → recall/precision, pass@k | Реализация |
| `regex-vs-llm-structured-text` | Гибрид «правила сначала, LLM для спорного» (линтер требований) | Реализация |
| `cost-aware-llm-pipeline` | Уложиться в лимиты подписки и бюджет API: роутинг моделей, ретраи, кеш | Реализация |
| `santa-method` | Два независимых ревьюера с одной рубрикой: верификация находок и финального отчёта | Реализация, сдача |
| `python-patterns`, `python-testing` | Единый стиль кода и pytest | Реализация |
| `verification-loop` | Проверка перед PR и перед сдачей: тесты, секреты, дифф | Перед PR, 27.11 |

Встроенные в Claude Code: `/code-review` (ревью диффа), `/security-review` (в том числе утечки ключей), `/init`.

## Агенты (`.claude/agents/`)

| Агент | Что делает |
|---|---|
| `researcher` | Исследует одну тему по веб-источникам и пишет `docs/research/<NN>-<тема>.md` |
| `fact-checker` | Перепроверяет цифры, ссылки и имена моделей в готовом файле исследования |
| `idea-critic` | Смотрит на идею или отчёт глазами жюри и ищет слабые места |

Вызов: попроси словами («запусти researcher на тему X») или упомяни `@agent-researcher`. Несколько субагентов работают параллельно, если попросить их запустить одновременно.

## Правила (`.claude/rules/`)

Правило в отличие от скилла Claude читает сам, без вызова. Чтобы не тратить контекст, правило подгружается только для нужных файлов (поле `paths` в его начале).

| Правило | Когда действует | Что в нём |
|---|---|---|
| `python.md` | Claude читает или правит `*.py` | Стиль, ошибки и битые файлы, секреты, тесты. Выжимка из правил ECC для Python, подогнанная под проект; для `experiments/` требования мягче |

## Если очень хочется плагин целиком

```
/plugin marketplace add affaan-m/ECC
/plugin install ecc@ecc
```

Не советуем на время хакатона (см. выше).

## Личный набор Нурдаулета (`claude-setup-kit`)

Нурдаулет собрал архив со своей конфигурацией Claude Code (установщик для Windows). Что в нём и что взяли в репозиторий (разбор 25.11):

| Что в наборе | Взяли? | Почему |
|---|---|---|
| Правила ECC: 121 файл для 22 языков | Только Python, переработанным в `.claude/rules/python.md` | Остальные языки нам не нужны. Общие правила ECC написаны для веб-сервисов (CSRF, SQL, покрытие 80 %, обязательный TDD, коммиты в английском формате) и ссылаются на агентов ECC, которых в репозитории нет |
| Плагин ECC целиком (~300 скиллов, хуки, в том числе GateGuard) | Нет | 10 нужных скиллов уже лежат в `.claude/skills/`, плагин их задублирует |
| Плагин Vercel, скиллы `shadcn` и `web-design-guidelines` | Нет | Агент консольный, веб-интерфейса и деплоя нет |
| 13 скиллов Remotion (видео на React) | Нет | Для отбора хватит записи терминала. Вернёмся к ним, если к финалу 4.12 решим делать видео |
| MCP `context7`, `playwright`, `github` | Нет | Документацию библиотек Claude и так читает из интернета, браузер агенту не нужен, для issues и PR хватает `gh` |
| Настройки: Opus, effort `xhigh`, Workflows | Нет | Это личный выбор; в общих настройках он навязал бы всем модель и расход лимита. Ставь у себя в `~/.claude/settings.json`, если хочешь |

Если ставишь набор себе целиком: в каждой сессии появятся правила всех 22 языков и ~300 скиллов ECC, а скиллы из этого репозитория задублируются. На время хакатона удали лишние языки из `~/.claude/rules/ecc/` (оставь `common` и `python`) или ставь с флагом `-SkipPlugins`. Ключей и токенов в наборе нет (проверено 25.11).
