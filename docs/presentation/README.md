# Презентация

| Файл | Что это |
|---|---|
| [`qairu-larpers-slides.pdf`](qairu-larpers-slides.pdf) | Слайды на сдачу, 15 страниц 16:9, собраны из `deck/` |
| [`deck/`](deck/) | Исходник слайдов: `deck.json` (порядок и шрифты), `deck.css` (дизайн), `slides/<id>.html` (слайд и заметки докладчика в `<aside>`) |
| [`build_pdf.py`](build_pdf.py) | Сборка PDF через headless Chrome, Chromium или Edge |
| [`check_text.py`](check_text.py) | Сверка текста двух PDF по страницам |
| [`storyboard.md`](storyboard.md) | Сюжет, источники цифр каждого слайда |
| [`defense.md`](defense.md) | Ответы на вопросы защиты |

Формат `deck/` тот же, что у артефакта Slides (ссылка в `storyboard.md`), так что файлы можно перенести туда без правок.

## Собрать PDF

```bash
uv run python docs/presentation/build_pdf.py
```

Нужен Chrome, Chromium или Edge (путь можно задать в `CHROME`) и интернет: шрифты Inter Tight, Inter и JetBrains Mono грузятся с Google Fonts. Заметки докладчика в PDF не попадают.

## Проверить, что текст не изменился

После правки дизайна текст слайдов должен совпасть со старым PDF до слова:

```bash
git show main:docs/presentation/qairu-larpers-slides.pdf > /tmp/old.pdf
uv run python docs/presentation/check_text.py /tmp/old.pdf docs/presentation/qairu-larpers-slides.pdf
```

Скрипт сравнивает по каждой странице порядок слов и их набор и завершается с кодом 1 при любом расхождении. Перенос по дефису в конце строки («44–» и «66») склеивается, так что другая ширина колонки ошибкой не считается.

## Дизайн

- **Цвет несёт смысл на всех слайдах:** янтарь = модель, кобальт = код, красный = критично. Тёмный фон только у обложки и итогового слайда.
- **Шрифты:** Inter Tight для заголовков и крупных чисел, Inter для текста, JetBrains Mono для команд, меток и кодов.
- **Кегли:** 24 px подписи и метки, 26–28 px текст, 32 px заголовки карточек, 64 px заголовки слайдов, 88–132 px ключевые числа. Ничего мельче 24 px, чтобы читалось с проектора.
- **Только графика без текста:** схема на обложке, иконки гарантий, стрелки конвейера, полосы и шкалы нарисованы в SVG и CSS. Фото, логотипов и подписей внутри графики нет.

Три правила, чтобы `check_text.py` проходил:

1. Текст меняется только в `slides/*.html`, и только если меняется смысл слайда. Для вёрстки можно добавлять обёртки `<div>` и `<span>`.
2. `text-transform: uppercase` только у `.eyebrow` и `.label`, как было. Иначе в PDF поменяется регистр слов.
3. Все блоки внутри `.body` позиционированы (`position: relative`), а строчные `<span>` нет. Так браузер пишет текст в PDF в порядке разметки.
