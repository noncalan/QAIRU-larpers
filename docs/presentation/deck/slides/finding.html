Находка из отчёта агента по requirements.pdf · reports/v1.0/report.json

Это настоящая находка из отчёта агента на документе кейса, а не макет. У неё четыре части. Первая: дословные цитаты с местом в документе. Их сверил код, текст в отчёт берётся из самого документа, а не из ответа модели. Вторая: пункт стандарта, который нарушен. Третья: пример-свидетель, то есть конкретный сценарий, на котором два требования дают разный результат. Тестировщик проверит его за десять секунд. Четвёртая: следующий шаг, то есть предложенная формулировка с пропуском и вопрос автору ТЗ. Слово «доказано» мы не пишем: пишем «пример, который это показывает». Источник: reports/v1.0/report.json, находка F-02 (требования R-06.1 и R-14, свойство «согласованность набора») и вопрос Q-01. Отчёт v1.0 собран из записи живого прогона 26.11.2026 и пересобирается командой с --backend replay; находки те же, что в кандидате RC2.
