Замеры

Решения по архитектуре приняты по замерам

Число проходов

Один проход поиска или три?

Правило записали до прогонов, применил его код. Три прохода дают +3,7 п. п. полноты при пороге +5, стоят в 1,9 раза дороже и сверяют 99,4 % цитат против 100 %.

Решение: один проход, три остаются флагом.

Формат ответа

Строгий JSON или свободный текст?

Со схемой JSON модель рассуждает меньше и находит 73 % дефектов эталона. Свободным текстом она находит 93 %.

Решение: поиск пишет текст, его разбирает код.

Критик находок

Нужна ли вторая модель-критик?

На двух форматах критик снял по одной находке, и обе оказались настоящими критичными дефектами. Шума он не убрал.

Решение: выключен по умолчанию, остаётся флагом.

Мы не усложняли агента ради сложности. Три места, где замер изменил архитектуру. Первое: число проходов. Пороги правила записали в план до прогонов, а применил его код, чтобы не подгонять решение под результат. Три прохода проиграли по правилу, и мы оставили один. Второе: со строгой схемой JSON модель думает в три-пять раз меньше и находит меньше, поэтому поиск пишет свободный текст в строгом формате, а разбирает его код. Третье: критик находок на замере снимал настоящие дефекты, а шум не убирал, поэтому по умолчанию он выключен.
