Архитектура

Доверие к отчёту обеспечивает код

Цитата есть в документе

Код ищет каждую цитату в исходнике и берёт текст оттуда, а не из ответа модели.

Нет цитаты, нет находки

Находка без сверенной цитаты в отчёт не попадает и уходит в «отброшено» с причиной.

Важность считает код

Номера, счётчики и светофор выводятся по таблице правил, а не моделью.

Модель не снимает находки

Снять находку или вопрос может только код и только по цитате-основанию из документа.

Отчёт пишется всегда

Битый файл, лимит или сбой шага превращаются в диагностику с кодом и подсказкой.

Прогон можно повторить

Отчёт пересобирается из записи без модели за секунды. CI зелёный на Linux, Windows и macOS, плюс gitleaks по всей истории.

Эталон только для замеров. Граница: пропуск модели код не видит (строго 14 из 27).
