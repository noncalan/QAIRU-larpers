# Идеи

Сюда складываем кандидатов идеи на сессию выбора (вечер 25.11). Один файл на кандидата: `docs/ideas/<короткое-имя>.md`.

## Шаблон кандидата

- **Суть в одном предложении.**
- **Что увидит жюри** (в отчёте и в репозитории).
- **Как закрывает ТЗ** (по пунктам `docs/case/task.md`).
- **Как бьёт в критерии:** архитектура, техреализация, точность, бизнес-ценность.
- **Битые файлы:** как обрабатываем.
- **Стоимость:** часы на реализацию, вызовы LLM на прогон.
- **Риски** и что будет, если не успеем (урезанная версия).

## Как выбираем

1. Каждый кандидат прогоняем через агента `idea-critic`.
2. Спорные развилки решаем скиллом `council`.
3. Решение записываем в `docs/decisions.md`, план режем скиллом `blueprint` на issues.
