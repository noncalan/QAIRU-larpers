# Ответы судьи для `--judge fake`

`judge/<номер прогона>.json` в формате `claude -p --output-format json`, как фикстуры агента в `tests/fixtures/llm/`.

`judge/1.json` придуман вручную для smoke-прогона eval на бэкенде `fake`: он сопоставляет пять находок из фикстур поиска (`tests/fixtures/llm/search/`) с номерами эталона. Это не ответ настоящего судьи и не метрика качества. Он нужен только затем, чтобы `python -m evals.eval ПАПКА --name smoke` на прогоне `--backend fake` считал метрики без сети. Если находки фикстур поменяются, номера находок вне списка eval отбросит с предупреждением.
