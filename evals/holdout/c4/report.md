### Q-01 · P0 · бизнес · владелец сотрудника
**Вопрос.** Пользователь A создал сотрудника без компании, у пользователя B есть свой сотрудник: кого A увидит в списке сотрудников без фильтра по компании?

**Где в документе.**
- «Пользователи могут регистрироваться, авторизоваться и выполнять CRUD-операции над своими компаниями и сотрудниками.» (раздел «c4_tech_task_example › Контекст (C1)», строка 7)
- «company\` (может быть null)» (раздел «Код (C4) › Требования к сущностям», строка 40)
- «Список сотрудников (всех или по компании).» (раздел «Код (C4) › Эндпоинты», строка 67)

**Почему важно.** У сотрудника нет ссылки на владельца, поэтому правило «свои сотрудники» не на чем реализовать; от ответа зависят схема БД и проверки доступа ко всем операциям с сотрудниками. Отдельно нужно задать обязательные поля и диапазон age, а также правила защиты персональных данных сотрудников.

| Вариант | Правило | Что поменять |
|---|---|---|
| A | Только своих сотрудников, включая не привязанных к компании | Добавить в Employee ссылку на пользователя-владельца, задаваемую из сессии; все операции с сотрудником разрешить только владельцу |
| B | Только сотрудников своих компаний; сотрудник без компании недоступен никому | Принадлежность сотрудника определять через компанию; описать, как создатель работает с сотрудником до привязки |
| C | Все сотрудники в системе общие: любой пользователь видит и меняет всех | Убрать «своими» для сотрудников; список без companyId возвращает всех сотрудников системы |
| Другое | ___ | |

**Если не ответить.** Команда добавит владельца сотрудника и покажет только своих; если сотрудники задуманы общими, придётся менять схему БД и тесты доступа.

### Q-02 · P0 · архитектор · companyId при создании

**Где в документе.**
- «Создать сотрудника: \`{ "firstName": "Иван", "age": 30, ... }\`.» (раздел «Код (C4) › Эндпоинты», строка 69)
- «Привязать к компании: \`{ "companyId": 1 }\` (или null).» (раздел «Код (C4) › Эндпоинты», строка 71)

**Почему важно.** Тела запросов на создание заданы с «...», поэтому неясно, можно ли привязать сотрудника сразу. Отдельно нужно зафиксировать полный состав полей, реакцию на неизвестные поля и то, что владелец компании берётся из сессии.
