### F-05 · критично · нарушение · Однозначность

- **Суть:** «и/или» в проверке доступа
- **Почему это проблема:** допускает реализацию без проверки владельца, то есть изменение чужих настроек.

  - если понимать как «обязательны обе проверки»: по цитате 1 → запрос отклонён, настройки карты B не изменились
- **Попытка теста:** тест написан по одному из двух прочтений документа: находка по-прежнему мешает тестированию
  - Предусловие: Клиент A вошёл в систему, его сессия действует. Существует карта клиента B.

  - Из документа «{"message":"Карта не найдена"}» (строка 191)
