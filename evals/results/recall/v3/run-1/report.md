1. **Q-01** · P0 (блокирует разработку) · кому: бизнес: Расходы марта 52 000 ₸, push в марте не было, клиент сохраняет порог 50 000 ₸ с включённым уведомлением: когда приходит push?

2. **Q-02** · P0 (блокирует разработку) · кому: архитектор: Владелец карты с действующей сессией сохраняет порог 999 ₸: метод отвечает HTTP 400 или HTTP 200 с result=ERROR?
   - Варианты: A. HTTP 200 с result=ERROR и message для любой ошибки проверки параметров; B. HTTP 400 для любой ошибки проверки, включая сумму вне диапазона; C. HTTP 200 ERROR для суммы вне диапазона, HTTP 400 для некорректного запроса (нет параметра, нечисловое значение, enabled не 0/1)
3. **Q-03** · P0 (блокирует разработку) · кому: бизнес: Порог 50 000 ₸, расходы 48 500 ₸; клиент оплатил 1 500 ₸ 10 марта, процессинг провёл покупку 12 марта: когда приходит push?
   - Варианты: A. 10 марта, при авторизации покупки; B. 12 марта, после проведения покупки
4. **Q-04** · P0 (блокирует разработку) · кому: архитектор, ИБ: Клиент с действующей сессией сохраняет порог для чужой карты demo-42: какой ответ возвращает метод?

5. **Q-05** · P0 (блокирует разработку) · кому: бизнес: Покупку на 4 000 ₸ совершили 31 января в 23:58, а провели 1 февраля в 00:03 по Алматы: в расходы какого месяца она входит?
   - Варианты: A. В январь, по дате совершения покупки; B. В февраль, по дате проведения покупки
