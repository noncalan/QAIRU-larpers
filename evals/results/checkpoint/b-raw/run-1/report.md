### Какие вопросы задать автору первыми

1. **Q-01** · P0 (блокирует разработку) · кому: архитектор: Клиент открывает экран «Уведомления» для карты с порогом 50 000 ₸: каким методом приложение получает порог, переключатель и сумму расходов за месяц?
   - Варианты: A. Отдельный метод чтения возвращает порог, переключатель и сумму за текущий месяц; B. Метод saveLimit без amount и enabled возвращает текущие значения и сумму; C. Порог и переключатель — новым методом чтения настроек, сумма за месяц — отдельным методом сервиса расходов
2. **Q-02** · P0 (блокирует разработку) · кому: архитектор: Клиент сохраняет порог 999 ₸: какой код и какое тело ответа получает приложение?
   - Варианты: A. 200 с result=ERROR и message; 400 — только при отсутствующем или нечисловом параметре; в телах 400/401/404/500 только message; B. 400 с телом из одного message; 200 возвращается только при result=OK; C. 400 с телом из result=ERROR и message; поле result есть во всех ответах
3. **Q-03** · P0 (блокирует разработку) · кому: архитектор, ИБ: Чужая карта получает 404: при каком запросе метод сохранения возвращает код 403 «доступ запрещён»?
   - Варианты: A. Никогда: 403 исключается, метод возвращает только 200, 400, 401, 404, 500; B. При действующей сессии без права изменять настройки уведомлений
4. **Q-04** · P0 (блокирует разработку) · кому: бизнес: Расходы месяца 30 000 ₸, клиент включает уведомление с порогом 20 000 ₸ или снижает порог до 20 000 ₸: приходит ли push?
   - Варианты: A. Да, push отправляется сразу после сохранения настройки; B. Нет, push в этом месяце не отправляется, пока расходы не перейдут порог снизу вверх
5. **Q-05** · P0 (блокирует разработку) · кому: архитектор: Порог 50 000 ₸ для карты demo-42 сохраняется запросом GET с параметрами в строке URL или запросом POST/PUT с JSON-телом?
   - Варианты: A. GET с query-параметрами без тела; B. POST или PUT с параметрами в JSON-теле
