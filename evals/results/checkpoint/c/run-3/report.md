### Какие вопросы задать автору первыми

1. **Q-01** · P0 (блокирует разработку) · кому: архитектор, ИБ: Если по чужой карте метод отвечает 404, в каком случае он возвращает 403?
   - Варианты: A. Код 403 не используется; статусы: 200, 400, 401, 404, 500; B. 403 для чужой карты, 404 только для отсутствующей; C. 403 для своей карты, недоступной для настройки (неактивна или не в KZT), 404 для чужой и отсутствующей
2. **Q-02** · P0 (блокирует разработку) · кому: бизнес: Расходы 30 000 ₸, порог 20 000 ₸, уведомление было выключено, клиент его включает: когда придёт push?
   - Варианты: A. Сразу при сохранении настройки; B. Не в этом месяце: push приходит только при переходе снизу через порог; C. При следующей покупке в этом месяце
3. **Q-03** · P0 (блокирует разработку) · кому: архитектор: Клиент сохраняет порог 999 ₸ или передаёт enabled=2: какой HTTP-код возвращает метод?
   - Варианты: A. 400 для любых неверных параметров; B. 200 с result ERROR; код 400 только для нарушенного формата запроса
4. **Q-04** · P0 (блокирует разработку) · кому: бизнес: Покупка совершена 31 января в 23:58, проведена 1 февраля в 00:03 по Алматы: в расходы какого месяца она входит?
   - Варианты: A. Январь, по дате совершения покупки по времени Алматы; B. Февраль, по дате проведения покупки по времени Алматы
5. **Q-05** · P0 (блокирует разработку) · кому: архитектор, ИБ: Метод сохраняет порог: параметры cardId, amount и enabled передаются в строке запроса GET или в теле JSON запроса POST или PUT?
   - Варианты: A. GET, параметры в строке запроса, тела нет; B. POST или PUT, параметры в теле JSON
