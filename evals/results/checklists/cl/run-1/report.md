1. **Q-01** · P0 (блокирует разработку) · кому: архитектор, ИБ: Клиент с действующей сессией сохраняет порог для карты другого клиента: метод возвращает 403 или 404?
   - Варианты: A. 404, как для отсутствующей карты: факт существования карты не раскрывается; B. 403 для чужой карты, 404 только для отсутствующей
2. **Q-02** · P0 (блокирует разработку) · кому: архитектор: Как передаются cardId, amount и enabled при сохранении порога: GET с параметрами в строке запроса или изменяющий метод с телом JSON?
   - Варианты: A. GET с параметрами в строке запроса, без тела и без Content-Type; B. PUT или POST с параметрами в теле JSON и обязательным Content-Type: application/json
3. **Q-03** · P0 (блокирует разработку) · кому: архитектор: Приложение отправляет порог 999 ₸ или признак включения 2: с каким кодом ответа метод отклоняет сохранение?
   - Варианты: A. Любое недопустимое значение суммы или признака — 400 с result=ERROR и описанием ошибки; B. Сумма вне диапазона — 200 с result=ERROR; неверный формат и недопустимый признак — 400; C. Любое недопустимое значение — 200 с result=ERROR; код 400 только для отсутствующих параметров
4. **Q-04** · P0 (блокирует разработку) · кому: архитектор: Клиент открывает экран уведомлений: откуда приложение получает текущий порог, переключатель и сумму расходов за месяц, если в части B описано только сохранение?
   - Варианты: A. Одна операция чтения возвращает порог, признак включения и расходы текущего месяца; B. Порог и признак читаются из настроек, расходы месяца — отдельной операцией сервиса расходов; C. Сумма за месяц на экране не показывается, приложение читает только настройки
5. **Q-05** · P0 (блокирует разработку) · кому: бизнес: Покупка на 4 000 ₸ совершена 31 января в 23:58, а проведена 1 февраля в 00:03 по Алматы: в расходы какого месяца она входит?
   - Варианты: A. В январь: месяц определяется по дате совершения покупки; B. В февраль: месяц определяется по дате проведения покупки
