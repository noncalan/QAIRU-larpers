# Сайт проекта

Сайт: [qairu-validator.vercel.app](https://qairu-validator.vercel.app/). Коротко об агенте, цифры, демо, команда и как запустить.

Исходник сайта (React и Vite) лежит в ветке [`feat/site-react`](https://github.com/noncalan/QAIRU-larpers/tree/feat/site-react/site), оттуда же он собирается и выкладывается на Vercel. В `main` его копии нет, чтобы не держать две версии с разными цифрами. Цифры на сайте взяты из README и отчёта на сдачу [`reports/v1.0/`](../reports/v1.0/README.md); если они расходятся, верен README.
